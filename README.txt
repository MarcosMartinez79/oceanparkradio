STREAMING CONFIGURADO:

PUBLICACIÓN EN GODADDY:
1. Entrá al hosting de GoDaddy.
2. Abrí el Administrador de archivos / File Manager.
3. Entrá a la carpeta pública del dominio (normalmente public_html o la carpeta asignada al dominio).
4. Subí los 3 archivos de este ZIP.
5. Si existe un index.html anterior, reemplazalo o hacé una copia antes.
6. Abrí https://oceanparkradio.com

IMPORTANTE:
El reproductor usa directamente la URL de streaming indicada. Si el servidor de streaming bloquea reproducción desde navegadores por HTTPS/CORS, el streaming puede requerir una configuración adicional del proveedor BRLogic. El sitio está preparado para probar primero la reproducción directa.
